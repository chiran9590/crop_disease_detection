# Crop Disease Detection

CNN-based image classification for plant leaf disease detection using the PlantVillage dataset.

## Project Structure

```
crop_disease/
├── data_pipeline.py      # Dataset loading, preprocessing, augmentation
├── train.py              # Model training (MobileNetV2 transfer learning)
├── evaluate.py           # Model evaluation (metrics, confusion matrix)
├── app.py                # Streamlit web interface
├── requirements.txt      # Python dependencies
├── class_names.json      # Disease class labels (auto-generated)
├── best_model.keras      # Trained model (saved after training)
├── training_history.png  # Training curves (generated after training)
├── confusion_matrix.png  # Confusion matrix (generated after evaluation)
├── classification_report.txt  # Detailed metrics (generated after evaluation)
└── sample_grid.png       # Sample images visualization (generated by pipeline)
```

## Setup

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Download dataset:**
   The dataset will be automatically downloaded from Kaggle on first run. Alternatively, place the PlantVillage dataset in a local folder and update the `dataset_path` in `data_pipeline.py`.

## Usage

### Training

Run the training script:
```bash
python train.py
```

This will:
- Load and preprocess the PlantVillage dataset
- Train a MobileNetV2-based model with transfer learning
- Save the best model as `best_model.keras`
- Save training curves as `training_history.png`
- Generate `class_names.json` for consistent labeling

### Evaluation

Run the evaluation script:
```bash
python evaluate.py
```

This will:
- Load the trained model
- Evaluate on the test set
- Display accuracy, precision, recall, F1 scores
- Save confusion matrix as `confusion_matrix.png`
- Save classification report as `classification_report.txt`

### Web Interface

Launch the Streamlit app:
```bash
streamlit run app.py
```

This will:
- Start a local web server
- Allow uploading leaf images for disease prediction
- Display predicted class, confidence score, and top-3 alternatives
- Show warnings for low-confidence predictions

## Configuration

### data_pipeline.py
- `dataset_path`: Path to PlantVillage dataset
- `image_size`: Target image size (default: 224x224)
- `batch_size`: Batch size for training (default: 32)
- `train_split/val_split/test_split`: Data split ratios (default: 70/15/15)

### train.py
- `use_transfer_learning`: Use MobileNetV2 transfer learning (default: True)
- `fine_tune_layers`: Number of top layers to fine-tune (default: 20)
- `initial_epochs`: Initial training epochs with frozen base (default: 10)
- `fine_tune_epochs`: Fine-tuning epochs (default: 10)
- `dropout_rate`: Dropout rate for regularization (default: 0.5)
- `l2_reg`: L2 regularization strength (default: 0.01)

### app.py
- `confidence_threshold`: Minimum confidence for valid predictions (default: 0.3)

## Model Architecture

- **Base Model**: MobileNetV2 (pre-trained on ImageNet, frozen initially)
- **Classification Head**: GlobalAveragePooling2D → Dense(128) → Dropout → Dense(num_classes, softmax)
- **Regularization**: Dropout (0.5), L2 regularization (0.01), data augmentation

## Evaluation Metrics

- Test accuracy
- Per-class precision, recall, F1 score
- Macro-average precision, recall, F1 score
- Confusion matrix visualization
- Detailed classification report
